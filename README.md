# VO₂ Breathe — PWA v6

## New in v6
- Wave Circle once again expands on inhale and contracts on exhale
- Cleaner wave design closer to the latest product mockup
- Breathe tab now leads with the large breathing player
- Breathing exercises are swipeable cards beneath the player
- Swiping a protocol selects it automatically
- Train-tab breathwork buttons now open the Breathe tab with the correct session pre-selected
- Larger Settings button
- Reworked bottom navigation icons to better match the mockup
- PWA manifest requests portrait-only orientation
- Landscape is blocked with a portrait-only message as a fallback
- Pinch zoom disabled via viewport configuration
- Existing local data migrates forward

Note: browser-level orientation locking is not guaranteed by every iOS/PWA environment, so this build also uses a CSS landscape blocker as a reliable visual fallback.
